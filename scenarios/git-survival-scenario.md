# Git Survival Lab Scenario

## Objective

Build a small project while practicing real-world Git workflows instead of isolated commands.

---

## Phase 1: Repository Setup

* Initialize Git repository
* Create project structure
* Create README
* Make initial commits

---

## Phase 2: Feature Development

### feature-login

Implemented login module:

* Login page structure
* Login validation

### feature-dashboard

Implemented dashboard module:

* Dashboard page
* Monitoring widgets

### feature-monitoring

Added monitoring roadmap and documentation updates.

### feature-alerts

Added alert monitoring features:

* CPU alerts
* Memory alerts

---

## Phase 3: Branching & Merging

Practiced:

* Creating branches
* Switching branches
* Fast-forward merge
* Three-way merge

---

## Phase 4: Merge Conflict Resolution

Created a conflict intentionally by modifying the same file in different branches.

Practiced:

* Conflict detection
* Manual conflict resolution
* Merge commit creation

---

## Phase 5: Git Recovery Operations

Practiced:

### Git Restore

Restore working directory changes.

### Git Stash

Temporarily save unfinished work.

### Git Revert

Create a new commit that reverses a previous commit.

### Git Reset

Tested:

* reset --soft
* reset --mixed
* reset --hard

---

## Phase 6: GitHub Integration

* Generated SSH keys
* Configured GitHub authentication
* Added remote repository
* Pushed all branches to GitHub

---

## Outcome

The lab covered a complete Git workflow including branching, merging, conflict resolution, recovery operations, and GitHub integration.
