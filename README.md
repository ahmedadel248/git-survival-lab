# Git Survival Lab

A hands-on Git learning project focused on practicing real-world Git workflows and recovery scenarios.

## Objectives

This repository demonstrates practical usage of:

* Git Branching
* Git Merge
* Merge Conflict Resolution
* Git Restore
* Git Stash
* Git Revert
* Git Reset (Soft, Mixed, Hard)
* GitHub Integration using SSH

## Project Workflow

### Phase 1: Repository Setup

* Create project structure
* Initialize Git repository
* Create initial commits

### Phase 2: Feature Development

* feature-login
* feature-dashboard
* feature-monitoring
* feature-alerts

### Phase 3: Merge Operations

* Branch merging
* Fast-forward merge
* Three-way merge

### Phase 4: Conflict Resolution

* Simulated merge conflict
* Manual conflict resolution

### Phase 5: Recovery Scenarios

* git restore
* git stash
* git revert
* git reset

### Phase 6: GitHub Integration

* SSH authentication
* Remote repository configuration
* Push local branches to GitHub

## Key Learning Outcomes

This lab focuses on understanding the relationship between:

* Working Directory
* Staging Area
* Local Repository
* Remote Repository

and how Git manages changes across each stage.
